Exercice complet : Installation d'Ubuntu à déploiement MkDocs

Cette page décrit la séquence complète depuis l’installation d’Ubuntu/WSL jusqu’au déploiement d’une page Markdown avec MkDocs et GitHub Pages.

A. Installation de l’environnement Linux (WSL / Ubuntu)

  1. Activer WSL sur Windows :

powershell wsl --install Installer Ubuntu depuis le Microsoft Store.

Créer un utilisateur Ubuntu lors du premier lancement.

Mettre à jour Ubuntu :

sudo apt update
sudo apt upgrade -y

B. Installation de Git

Installer Git :

sudo apt install git

Vérifier l’installation :

git --version

Configurer Git :

git config --global user.name "TonNom"
git config --global user.email "tonemail@gmail.com"

C. Préparation du projet

Créer le dossier du projet et se déplacer dedans :

mkdir ~/idgeo
cd ~/idgeo

Initialiser Git et renommer la branche principale :

git init
git branch -m main

Créer le dossier docs et le sous-dossier pour les images :

mkdir -p docs/img

D. Création d’un environnement virtuel Python et installation de MkDocs

Installer le package venv (si nécessaire) :

sudo apt install python3-venv

Créer l’environnement virtuel :

python3 -m venv venv

Activer l’environnement virtuel :

source venv/bin/activate

Installer MkDocs :

pip install --upgrade pip
pip install mkdocs
mkdocs --version

⚠️ Toujours activer l’environnement virtuel avant d’utiliser MkDocs.

E. Configuration de MkDocs

Créer le fichier mkdocs.yml à la racine du projet :

site_name: Mon Projet IDGEO
docs_dir: docs
theme: readthedocs
nav:
  - Accueil: index.md
  - Étapes: etapes.md
  ```
## F. Création des fichiers Markdown
Fichier docs/index.md :

# Bienvenue sur Mon Projet IDGEO

Ceci est un exemple de site Markdown avec MkDocs.


## Instructions

- Modifier ce fichier pour ajouter votre contenu.
- Les changements se rechargent automatiquement avec `mkdocs serve`.
- Le site peut être déployé sur GitHub Pages avec `mkdocs gh-deploy`.
Fichier docs/etapes.md (cette page) :

Déjà en cours de lecture ici ; ce fichier contient toutes les étapes de A à G.

Ajouter l’image dans docs/img/ign.png.

### G. Visualisation locale et construction du site
Lancer le serveur de développement :

mkdocs serve
Ouvrir dans le navigateur :

http://127.0.0.1:8000/
Le site se recharge automatiquement à chaque modification des fichiers Markdown.

Construire le site statique pour déploiement :

mkdocs build
Les fichiers HTML sont générés dans le dossier site/.

H. Déploiement sur GitHub Pages
Créer un dépôt sur GitHub (ex. : cpgeom).

Ajouter le dépôt distant et pousser le projet :

git remote add origin https://chafiiabdi.github.io/cpgeom

git add . git commit -m "Ajout site" git push -u origin main

Déployer le site avec MkDocs :

mkdocs gh-deploy ```
