Étapes complètes de l’exercice

Cette page décrit la séquence complète depuis l’installation d’Ubuntu jusqu’au déploiement de la page Markdown avec MkDocs.

A. Installation de l’environnement Linux (WSL / Ubuntu)

  1. Activer WSL sur Windows : powershell wsl --install

Installer Ubuntu depuis le Microsoft Store.

Mettre à jour Ubuntu :

sudo apt update
sudo apt upgrade -y

B. Installation de Git

Installer Git :

sudo apt install git

Configurer Git :

git config --global user.name "TonNom"
git config --global user.email "tonemail@gmail.com"

C. Préparation du projet

Créer le dossier :

mkdir ~/idgeo
cd ~/idgeo

Initialiser Git :

git init
git branch -m main

Créer le dossier docs et le sous-dossier img :

mkdir -p docs/img

D. Création d’un environnement virtuel et installation de MkDocs

python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install mkdocs
mkdocs --version

E. Configuration de MkDocs

Créer mkdocs.yml :

site_name: Mon Projet IDGEO
docs_dir: docs
theme: readthedocs

F. Visualisation et construction du site

Lancer le serveur local :

mkdocs serve

Construire le site :

mkdocs build

G. Déploiement sur GitHub Pages

git remote add origin git@github.com:username/idgeo.git
git add .
git commit -m "Ajout site"
git push -u origin main
mkdocs gh-deploy

Le site sera disponible sur :

https://username.github.io/idgeo/

## **3️⃣ Fichier `mkdocs.yml`**

Place ce fichier à la racine de `idgeo/` :

```yaml
site_name: Mon Projet IDGEO
docs_dir: docs
theme: readthedocs
nav:
  - Accueil: index.md
  - Étapes: etapes.md

4️⃣ Instructions finales

Mettre l’image dans docs/img/ign.png.

Activer ton environnement virtuel avant de lancer MkDocs :

source venv/bin/activate

Lancer le serveur local :

mkdocs serve

Ouvrir dans le navigateur :

http://127.0.0.1:8000/

Déployer sur GitHub Pages :

mkdocs gh-deploy
